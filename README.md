# Hollow Hands 0.7.0

Minecraft Java 26.3 · Fabric · Java 25.

## Visible equipment
Four custom, textured 3D pieces are rendered on the player: a belt at the waist, a backpack on the back, a satchel at the hip, and a bandolier across the chest. The render layer also resolves actual stored ItemStacks through Minecraft's item-model renderer, so carried items appear as 3D models attached to the corresponding compartment.

## Storage
- Belt: 2 slots
- Back: 6 slots
- Satchel: 9 slots
- Bandolier: 4 slots

Press G. Hold an item and choose an empty slot, then Store held stack. Select a populated slot and choose Take selected slot. Storage is player-attached, saved, server-authoritative and synchronized. Install on both client and server.

## Planned gameplay systems
Weight and bulk, two-handed item restrictions, hit fumbles, swimming drops, upgradeable backpacks/quivers/tool belts/sheaths, miner and knight loadouts, and pack-animal/cart logistics are not yet implemented in this release.
